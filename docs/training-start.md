# Почему models пустая

Фотографии сохраняются как размеченные примеры. Файл candidate-*.pt и отчёт .json появляются в models только после успешного обучения. Точный путь показан на вкладке «Обучение»; при запуске ярлыком этого ПК это D:/pikkaBPE/data/models.

Три снимка одного товара — один класс. Этот классификатор обучается отличать товары друг от друга, поэтому один класс не подходит. Нужны:

1. Снимки первого и второго товаров в одной съёмке.
2. Новая независимая съёмка обоих товаров с другими кадрами. Нажмите «Новая съёмка» и импортируйте фотографии для обоих товаров с этим идентификатором.
3. «Обучить на NVIDIA». Дождитесь успешного завершения, проверьте отчёт и нажмите «Активировать модель».

Не дублируйте фотографии между обучением и проверкой. Малое количество примеров подходит только для проверки процесса; оно не доказывает точность складского распознавания. Создание модели для одного товара потребует отдельного режима сравнения с эталонами либо примеров «другие предметы/фон»; текущий выпуск такой режим не заявляет.
