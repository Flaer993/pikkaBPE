# pikkāBPE 0.1.0 — домашний операторский прототип

Windows-клиент: просмотр камеры/видео, разметка предметов, подтверждаемый складской
журнал, SQLite, CSV и загрузка обновлений по подтверждению. Обучение MobileNetV3 Small
в отдельном CUDA-окружении. Начальные модели не принимают складских решений автономно.

Механика: компоновка SolidWorks 2024 P0 и посадочные образцы STEP/STL. Не является
проверенной потолочной конструкцией; см. manual.pdf и список незавершённых сопряжений.

Прошивка: проверяемое ядро C99 и HAL adapter. BIN/HEX для PB_MCU01_H503A отсутствуют,
пока не подтверждена распиновка платы. Этот релиз не обновляет MCU по UART.

Клиент без Authenticode-подписи. Проверяйте SHA256SUMS.txt. Данные хранятся вне каталога
приложения. Для обучения установите Python 3.11 и зависимости согласно README.
