# pikkāBPE 0.3.0 — YOLO + OpenCV

YOLOv8n обнаруживает несколько предметов во всём видеокадре и подписывает рамки названиями из справочника. OpenCV обрабатывает видео, CUDA работает в отдельном постоянном процессе. Старый классификатор сохранён.

Добавлена разметка полного кадра несколькими рамками. Обучение допускает один класс и требует две независимые съёмки. Обновлены инструкция docs/yolo.md и PDF.

Пилот на RTX 3060: 8 исходных изображений, 32 синтетические композиции, 8 классов, 100 эпох. Независимой оценки качества нет. Модель активируется оператором отдельно. Для EXE требуется Python-окружение с requirements-yolo.txt. Условия Ultralytics AGPL-3.0/Enterprise описаны в инструкции.

Проверки: 32 теста, CUDA-инференс нескольких предметов, видеопоток. CAD и прошивка без функциональных изменений.
