# pikkāBPE 0.1.2 - сотрудники, фотографии и штрихкоды

- Вкладка «Сотрудники и товары»: добавление ФИО без ручного кода и изменение имени.
- Обучение по фотографиям: выбор товара, пакетный импорт, счётчик примеров и съёмок, проверка готовности перед обучением NVIDIA.
- Удаление событий отменяет влияние на остатки и размещение поступления. Отрицательный остаток запрещён; исходное событие остаётся в аудите и исключается из CSV.
- Для нового товара без кода автоматически создаётся внутренний код PB и печатная этикетка Code 128 в SVG. Для существующего штрихкода этикетку можно открыть повторно.
- Существующая БД обновляется при запуске. Обновление клиента устанавливается после подтверждения оператора.

Проверки: 21 pytest-тест, включая миграцию БД, отмену операций, импорт фотографий и сценарий интерфейса. PDF обновлён.

Для обучения нужны минимум два товара, каждый в независимых обучающей и проверочной съёмках. Распознавание сотрудников и автономное списание в этом выпуске не добавлены. Контроллер прошивается через ST-Link; CAD P0 и аппаратная проверка остаются на прежнем этапе.
