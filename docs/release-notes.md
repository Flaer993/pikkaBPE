# pikkāBPE 0.1.1 - PB_MCU01_H503 и CI/CD

По схеме V1.0 добавлена ARM-прошивка STM32H503CBT6: USB CDC ACM, PA0/H1-5 и
PA1/H1-6 для MG995, 50 Гц PWM, CRC команд, плавное движение задания и удержание
при потере связи. Плата имеет прямой USB, отдельного USB-UART моста нет.

BIN/HEX/ELF - стендовый кандидат, ещё не испытанный на физической плате.
Подключение и первая проверка: docs/board-wiring.md и PDF-руководство.

GitHub Actions проверяет Python/UI и C, собирает Windows-клиент и прошивку ARM,
публикует выпуск по тегу. Клиент обновляется после подтверждения оператора.
Прошивка контроллера пока обновляется через ST-Link, не из клиента.

CAD P0 остаётся предварительной компоновкой. Складские операции подтверждает
оператор. Windows-клиент без Authenticode-подписи.
