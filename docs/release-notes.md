# pikkāBPE 0.1.3 - логотип и понятное начало обучения

Добавлены векторный логотип, PNG и многоразмерная Windows-иконка. Логотип отображается в шапке клиента, иконка встроена в EXE и окно.

Вкладка обучения показывает путь к моделям, число файлов .pt и поясняет, почему импорт фотографий сам по себе не создаёт модель. При недостатке данных интерфейс сообщает, какие фотографии требуется добавить. Успешное и неуспешное завершение обучения отображаются отдельно.

Для текущего классификатора нужны минимум два разных товара и независимые съёмки каждого для обучения и проверки. Три фотографии одного товара остаются одним классом; проверка данных сохранена. Пользовательские фотографии и база не изменялись.

Проверено: 23 теста pytest; интерфейс при 1400 x 900; векторная иконка и PNG. Исходник логотипа: pikkabpe/assets/logo.svg; Windows ICO: pikkabpe/assets/app.ico.
