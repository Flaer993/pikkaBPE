# pikkāBPE 0.1.4 - названия товаров и распознавание в видео

Результаты распознавания показывают название из справочника вместо штрихкода. На вкладке «Наблюдение» добавлено непрерывное распознавание выбранной области либо всего кадра, подпись поверх видео, порог оценки и пометка «Не уверен».

Модель работает в отдельном постоянном процессе Python/PyTorch: загрузка один раз, не более одного кадра в обработке, без записи кадров на диск. Устаревшие результаты отбрасываются. Код процесса включён в Windows-обновление. Разовая проверка выделенного предмета использует тот же процесс.

Это классификация одной области, не автоматический поиск нескольких объектов. Рамку выделяет оператор, либо анализируется весь кадр. Складские остатки автоматически не изменяются.

Проверки: 26 тестов pytest; реальные запросы к активной модели на RTX 3060 (CUDA); обработка названий, низкой оценки, частичных сообщений и устаревших результатов. Подробности: docs/live-recognition.md.
