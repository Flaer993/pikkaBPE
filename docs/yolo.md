# YOLO + OpenCV / 0.3.0

OpenCV получает и обрабатывает видео. YOLOv8n находит несколько предметов во всём кадре. Клиент подписывает рамки названиями из справочника. Остатки меняются после подтверждения оператора.

## Запуск

Зависимости на этом ПК установлены в .venv. На другом ПК выполните scripts/setup.ps1 либо установите requirements-yolo.txt в окружение Python с индексом https://download.pytorch.org/whl/cu118. EXE использует внешнее окружение; PyTorch и веса в него не включены.

В разделе «Обучение» активируйте data/models/yolo-catalog-pilot.pt. Одноимённый JSON должен находиться рядом. Откройте камеру/видео и включите «Распознавать предмет на видео». YOLO использует весь кадр; старый классификатор работает с выбранной областью.

## Обучение на своих кадрах

1. Выберите режим YOLO и откройте фотографию или остановите кадр камеры.
2. Выберите товар, обведите предмет мышью и нажмите «Добавить рамку YOLO».
3. Повторите для всех видимых экземпляров известных товаров. Нажмите «Сохранить разметку кадра».
4. После новой независимой съёмки с другими ракурсами, фоном и освещением нажмите «Новая съёмка» и разметьте новые кадры.
5. Нажмите «Обучить на NVIDIA». Нужны две независимые съёмки с каждым товаром. Одного класса достаточно. Проверьте результат и активируйте модель.

Сохраняется полный кадр со всеми рамками. Фотографии классификатора без рамок не становятся автоматически разметкой YOLO. Данные: data/detection; модели: data/models. Проверочная съёмка отделяется целиком. Разные названия сессий одной фотографии не создают независимую проверку.

## Каталожный пилот

RTX 3060: 100 эпох, 8 классов, 8 исходных иллюстраций intellectual.energy и 32 синтетические композиции. Рамки исходных изображений предложены OpenCV и просмотрены вручную. Композиции относятся к той же исходной сессии. Независимых складских кадров нет, точность и mAP не заявляются. Похожие артикулы могут путаться; высокая оценка не гарантирует правильный ответ. Активная модель оператора не заменяется автоматически.

Подготовка: scripts/prepare_yolo_pilot.py; отчёт: docs/yolo-training-report.json; источники: docs/catalog-sources.json. Базовые веса: https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n.pt. Общая COCO-модель сама по себе не знает складские артикулы.
