# Проверка интеграции склада, 2026-09-16

- Python: 46 тестов прошли, включая весь прежний набор.
- Проверены точные строки Code128, EAN-13, QR и Data Matrix, координаты на полном
  кадре, повторное чтение одной области и одинаковые коды на разных этикетках.
- Проверено, что код переносится в форму только по выбору оператора и не создаёт
  событий/остатков. Общий класс не принимается за совпавший код каталога.
- Предразметка не попадает в датасет до назначения товара и сохранения кадра;
  проверено исправление предложенной рамки.
- Проверены выбор прежнего `.pt` в команде обучения, отказ обучать ONNX, сериализация
  NumPy-счётчиков в JSON и загрузка ONNX на путях с кириллицей.
- Реальный WarehouseLogistics запущен через OpenCV на примере автора: получены
  рамки человека, погрузчика и паллет. Это проверка работоспособности на одном
  изображении, не измерение качества.
- Реальный процесс распознавания и UI прочитали `INTER-ER14505-001` на техническом
  изображении 1800×1000. Проверяется передача исходного разрешения и точной строки.
- Продолжение обучения от ранее созданного checkpoint прошло на синтетическом
  техническом наборе: сохранены новые веса, исходные/итоговые SHA-256, съёмки и
  метрики по классу. В тестовом harness устройство переключено на CPU, так как
  обе GPU были заняты; обычный UI по-прежнему обучает на NVIDIA. Тестовую модель
  не активировали, её отчёт помечен как непроверенный на реальном складе.
- Windows-клиент собран; запуск EXE проверен в offscreen-режиме. В ZIP включены
  исходники внешнего процесса; модели и CUDA-библиотеки в ZIP не входят.

Окружение: Windows, Python 3.11.9, PySide6 6.8.3, OpenCV 4.11.0.86,
NumPy 2.1.3, Ultralytics 8.3.203, ZXing-C++ 2.3.0. Для технической проверки обучения
использован доступный PyTorch 2.5.1+cu121. Целевой профиль установки проекта cu118
не менялся; производительность на Pascal P4000 не проверялась.

Реальных складских кадров и действующей товарной модели в этой копии репозитория
нет. Точность распознавания артикулов, доля читаемых этикеток, работа с движением,
бликами и перекрытиями требуют отдельного испытания на вашем складе.
