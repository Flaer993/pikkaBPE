# Распознавание в видео

Активируйте модель через «Обучение», откройте камеру/видео и включите «Распознавать предмет на видео».

YOLO находит несколько предметов во всём кадре и показывает рамки с названиями. Старый классификатор распознаёт одну выбранную область. [Инструкция YOLO](yolo.md).

Модель загружается один раз в отдельном Python-процессе, при доступности CUDA использует NVIDIA. OpenCV передаёт кадры в памяти, снимки для распознавания не сохраняются. Запросы отправляются примерно два раза в секунду без накопления очереди; результаты старше двух секунд и от предыдущего источника игнорируются. При остановке процесс освобождается.

Это периодическое обнаружение без постоянных идентификаторов объектов между кадрами. Операции подтверждает человек. Оценка модели не гарантирует правильность распознавания незнакомых или похожих товаров.
