# Распознавание в видео

1. Обучите модель и активируйте её на вкладке «Обучение».
2. Откройте камеру либо видео на вкладке «Наблюдение».
3. Включите «Распознавать предмет на видео».
4. Выделите предмет мышью. Кнопка «Весь кадр» снимает выделение.

Название берётся из справочника товаров по коду модели. Оно отображается поверх кадра и в разовой подсказке. Если товар удалён из справочника, клиент сообщает об этом. При оценке ниже выбранного порога выводится «Не уверен». Оценка модели не является гарантией правильности; незнакомый предмет может получить высокую оценку известного класса.

Текущая модель классифицирует одну область: рамку оператора либо весь кадр. Она не обнаруживает автоматически несколько объектов и не отслеживает перемещение рамки за предметом. Чтобы узнавать мелкий предмет, выделите его крупно. Складские события по-прежнему подтверждает оператор.

Модель загружается один раз в отдельном процессе Python с PyTorch, по возможности на CUDA. Кадры передаются в памяти; снимки видеопотока не записываются на диск. Частота запросов ограничена примерно двумя в секунду, очередь не накапливается. Результаты старше двух секунд и результаты предыдущего источника/области игнорируются. При остановке камеры процесс освобождается.

Для Windows EXE код процесса распознавания поставляется внутри обновления. Python/PyTorch берутся из настроенного окружения обучения. Не запускайте обучение одновременно с видеораспознаванием на видеокарте с недостаточной памятью.
